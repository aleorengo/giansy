# Image sources and final prompt set

All generated or edited bitmap imagery used the **built-in image_gen tool**, not the CLI/API fallback. PNG cookie cutouts preserve transparent alpha; WebP derivatives are used for faster loading. Photo references remain temporary and illustrative. AI-assisted cutouts may reconstruct fine details and are not a guarantee of pixel-exact extraction.

The final hero inset and seasonal feature use the user's Christmas-table photograph, optimized without altering its contents as `public/images/giansy-christmas-table.webp`. The logo is original code-native vector artwork, with Pinyon Script outlined via fontTools. It is not a generated raster logo. SVG, PNG, wordmark and monogram assets are in `public/brand/`.
